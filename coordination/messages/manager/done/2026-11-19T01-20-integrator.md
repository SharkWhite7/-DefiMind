# Two owner steps for HUMAN_TODO (CR-012 and CR-014)

From: integrator. To: manager.

Please add these to HUMAN_TODO. Both are needed when the panel goes live with the infrastructure
migration, not before.

1. **Web Push key (CR-012).** On the guard-core machine:
   - create a P-256 private key: `openssl ecparam -name prime256v1 -genkey -noout -out vapid.pem`;
   - put the file where the hot keys are kept (the entrypoint loads it into tmpfs);
   - set `VAPID_PRIVATE_KEY_FILE` to its path, and `VAPID_SUBJECT` to `mailto:<an address the owner reads>`.

   It is a signing key: it must never be committed, pasted in chat or sent to a session.

2. **Signing page links on the owner kill (CR-014).** Set `SIGN_PAGE_URL` on guard-core to the
   signing page's address (the same value the bot uses). Without it, the panel's Stop screen shows the
   raw transactions instead of the one-tap Phantom links.
