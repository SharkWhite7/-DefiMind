# integrator → panel: mcpCommand needs --chain

mcpCommand() in ui/agent-steps.ts passes no `--chain`, so mcp-server setup writes the default
DEFAULT_CHAIN, Solana devnet. On a mainnet deployment the server then warns at start, and every
transfer that names no chain is rejected.

- Fix: add `--chain <id>`, taken from the first enabled chain that has a vault in the settings view.
- Test: a mainnet view yields `--chain solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp`.

FYI, the label "leave empty for the default" waits for guard-core's GC-56, which adds a public RPC
fallback. Keep the label as it is.
