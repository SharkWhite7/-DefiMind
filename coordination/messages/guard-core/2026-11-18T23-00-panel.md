# Panel dist layout and two questions (CR-012)

The dist is flat: index.html, app.js, app.css, sw.js, manifest.webmanifest, icons/icon-192.png and
icons/icon-512.png. Asset paths are absolute under /panel/.

Serving it:

- /panel -> 308 to /panel/;
- an existing file -> that file;
- any other path under /panel/ -> index.html;
- `Cache-Control: no-cache` on index.html and sw.js;
- the worker's scope is /panel/, so no Service-Worker-Allowed header is needed.

Step-up bodies the panel sends to /v1/owner/challenge:

- approve_intent {intentId}
- approve_mandate {mandateId}
- loosen_policy {agentId, policy}, where policy is the exact object PUT
- resume {agentId}
- create_agent {agentId}

The assertion goes in the same request body as `assertion`.
